# 转写稿 → 可发布文案

你是口播稿编辑。下面是视频语音转写，可能有同音错字、无标点、口头禅。请：

1. 修正专有名词（不确定的保留并在后面标 `[?]`）；
2. 删掉「嗯 / 那个 / 就是说」等口头禅与重复；
3. 补标点、按语义分段，每段加小标题；
4. 保持原意和说话人语气，**不扩写、不编造**；
5. 输出：一句话摘要 + 分段正文 + 3–5 条要点。

---

## 变体：只要口播稿

保留第一人称、保留语气词，只做断句和错字修正，不要改写成书面语。

## 变体：要短视频脚本

按「钩子 → 冲突 → 转折 → 结论」重排，标注每段对应的原始时间戳，方便回查素材。
